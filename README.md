# ARSPN medical data analysis
this project analyzed medical imaging records from ARSPN dataset. it demonstrates data cleaning, exploratory analysis and visualization of clinical data.

# Project overview
analysis of patient demographics, imaging modalities and lesion characteristics to answer questions such as age distribution, lesion severity and modality usage.

# Dataset
ARSPN medical imaging records
Cleaned dataset: ARSPN_cleaned_final_real.xlsx

# Visualizations
all figures are in the images folder
* age distribution.png--distribution of patient age
* imaging records by modality.png-- count of records by modality
* age vs lesion size.png-- relationship between age and lesion size
* lesion severity with age.png--how lesion severity changes with age

# Tools used
Python, Pandas, Matplotlib, excel, git and github

# Key insights
* the highest number of patients are aged between 50-60 years
* conventional X-ray is the most frequently used modality
* lesion size tends to increase with age
